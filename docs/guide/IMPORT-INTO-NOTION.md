# Import this guide into Notion

**What this page is for:** five quick steps to copy these pages into your own Notion.

1. Keep all the `.md` files in this folder together. Zip the folder if you like.
2. In Notion open **Settings**, then **Import**, then **Markdown & CSV**. Choose the files (or the zip). You can also drag the `.md` files onto a Notion page.
3. Notion makes one page per file. Open `README` first and move the pages under it in order.
4. Diagrams are Mermaid code blocks and should draw as pictures. If one shows as plain code, click the block's language label and switch it to **Mermaid**.
5. If a link between pages does not open, link it by hand with `@` and the page name.

> ⚠️ **Careful:** Do not add real tokens or keys to Notion pages.
