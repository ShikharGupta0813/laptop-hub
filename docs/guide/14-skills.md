# 14 · Skills: teach Jarvis and Friday new tricks

**What this page is for:** adding community skills without writing code.

A **skill** is a short instruction file someone else wrote, for example "how to search arXiv" or "how to explain code". Installing one gives Jarvis or Friday a new how-to to follow. No code runs.

## Add one
- Say or type: "**install the arxiv skill**". You get an approval card with the name, where it comes from, what it does and its size. Tap Approve.
- Or open **Apps, Skills, Browse**, pick a catalog (Hermes Agent or OpenClaw) and tap Install, or paste a GitHub link like `owner/repo/path/to/skill`.

## Use one
Say "**use the code-explainer skill on this**" and paste or describe the thing. Turn a skill off any time with its switch, or Remove it.

## Who gets it
A skill can say it is for Jarvis (code, files, terminal), Friday (mail, calendar, plans) or both. A cyan badge means Jarvis, amber means Friday. Each voice only sees its own.

## Staying safe
Skills are written by strangers, so each shows an "untrusted community skill" badge. They are only text: they cannot change your settings, give permissions or run anything. If a skill suggests an action, you are asked first as usual. Scripts inside a skill are listed, never run. Only GitHub is allowed as a source.

Turn the feature off with `skills_enabled: false` in Settings.
